
### מבוא לפיתוח צד שרת עם Node.js

Node.js הוא סביבה שמאפשרת להריץ קוד JavaScript בצד השרת. הוא נמצא בשימוש רחב לבניית יישומים אינטרנטיים סקיילביליים ויעילים. מדריך זה נועד לספק סקירה מפורטת על פיתוח צד שרת עם Node.js, מותאם למתחילים.

#### מושגי יסוד בפיתוח צד שרת

1. **שרת**: תוכנה שמאזינה ומעבדת בקשות מלקוחות (למשל, דפדפנים).
    
2. **API (ממשק תכנות יישומים)**: סט חוקים שמאפשר תקשורת בין רכיבי תוכנה.
    
3. **בסיס נתונים**: אוסף נתונים מובנה. אפשרויות פופולריות כוללות MongoDB, MySQL ו-PostgreSQL.
    
4. **ניתוב**: מיפוי בקשות נכנסות לפונקציות קוד ספציפיות.
    
5. **Middleware**: פונקציות שרצות במהלך מחזור החיים של בקשה לשרת.
    

#### כלים וספריות

- **Node.js**: להרצת JavaScript בצד השרת.
    
- **Express.js**: פריימוורק מינימלי ל-Node.js.
    
- **Sequelize**: ספרייה לעבודה עם בסיסי נתונים מסוג PostgreSQL.
    
- **dotenv**: לניהול משתני סביבה.
    

### הקמת סביבת עבודה עם Node.js

1. **התקנת Node.js** הורד והתקן את Node.js מהאתר הרשמי: [official website](https://nodejs.org/).
    
2. **יצירת פרויקט חדש** פתח טרמינל והרץ את הפקודות הבאות:
    
    ```
    mkdir my-backend-project
    cd my-backend-project
    npm init -y
    ```
    
    פקודות אלו ייצרו קובץ `package.json` לניהול התלויות של הפרויקט.
    
3. **התקנת חבילות נדרשות**
    
    ```
    npm install express sequelize pg pg-hstore dotenv
    ```
    

### יצירת שרת בסיסי עם Express

1. **מבנה הפרויקט**
    
    ```
    my-backend-project/
    |-- server.js
    |-- .env
    |-- models/
    |-- routes/
    ```
    
2. **יצירת** `**server.js**`
    
    ```
    const express = require('express');
    const dotenv = require('dotenv');
    
    dotenv.config();
    
    const app = express();
    const PORT = process.env.PORT || 3000;
    
    app.use(express.json());
    
    app.get('/', (req, res) => {
        res.send('ברוכים הבאים לשרת הבקאנד!');
    });
    
    app.listen(PORT, () => {
        console.log(`השרת פועל בכתובת http://localhost:${PORT}`);
    });
    ```
    
3. **הרצת השרת**
    
    ```
    node server.js
    ```
    
    בקר בכתובת `http://localhost:3000` בדפדפן כדי לראות את ההודעה.
    

### חיבור ל-PostgreSQL עם Sequelize

1. **הגדרת בסיס נתונים PostgreSQL** צור בסיס נתונים חדש בשם שתבחר בעזרת כלי ניהול כמו pgAdmin או דרך שורת הפקודה.
    
2. **יצירת קובץ חיבור**
    
    ```
    // models/db.js
    const { Sequelize } = require('sequelize');
    
    const sequelize = new Sequelize(process.env.DATABASE_URL, {
        dialect: 'postgres',
        protocol: 'postgres',
        logging: false,
    });
    
    const connectDB = async () => {
        try {
            await sequelize.authenticate();
            console.log('חיבור ל-PostgreSQL הצליח');
        } catch (error) {
            console.error('חיבור ל-PostgreSQL נכשל:', error.message);
            process.exit(1);
        }
    };
    
    module.exports = { sequelize, connectDB };
    ```
    
3. **עדכון** `**server.js**` **לחיבור לבסיס נתונים**
    
    ```
    const { connectDB } = require('./models/db');
    
    connectDB();
    ```
    
4. **הוספת URI לבסיס הנתונים בקובץ** `**.env**`
    
    ```
    DATABASE_URL=postgres://username:password@localhost:5432/mydatabase
    ```
    

### יצירת מודלים ותרשימי נתונים (Schemas)

1. **יצירת מודל לסטודנטים**
    
    ```
    // models/Student.js
    const { DataTypes } = require('sequelize');
    const { sequelize } = require('./db');
    
    const Student = sequelize.define('Student', {
        name: { type: DataTypes.STRING, allowNull: false },
        age: { type: DataTypes.INTEGER, allowNull: false },
        email: { type: DataTypes.STRING, allowNull: false, unique: true },
    });
    
    module.exports = Student;
    ```
    

### הוספת פעולות CRUD

1. **יצירת קובץ ניתוב**
    
    ```
    // routes/studentRoutes.js
    const express = require('express');
    const Student = require('../models/Student');
    const router = express.Router();
    
    // יצירת סטודנט חדש
    router.post('/students', async (req, res) => {
        try {
            const student = await Student.create(req.body);
            res.status(201).json(student);
        } catch (error) {
            res.status(400).json({ error: error.message });
        }
    });
    
    // קבלת כל הסטודנטים
    router.get('/students', async (req, res) => {
        try {
            const students = await Student.findAll();
            res.json(students);
        } catch (error) {
            res.status(500).json({ error: error.message });
        }
    });
    
    module.exports = router;
    ```
    
2. **עדכון** `**server.js**` **לשימוש בנתיבים**
    
    ```
    const studentRoutes = require('./routes/studentRoutes');
    
    app.use('/api', studentRoutes);
    ```
    

### בדיקת ה-API

השתמש בכלים כמו [Postman](https://www.postman.com/) או [Insomnia](https://insomnia.rest/) כדי לבדוק את נקודות הקצה של ה-API:

- **POST /api/students**: יצירת סטודנט חדש.
    
- **GET /api/students**: קבלת כל הסטודנטים.
    

### תכונות נוספות

- **Middleware לטיפול בשגיאות**:
    
    ```
    app.use((err, req, res, next) => {
        console.error(err.stack);
        res.status(500).send('משהו השתבש!');
    });
    ```
    
- **אימות והרשאות**: השתמש בספריות כמו `jsonwebtoken` לאימות מאובטח של ה-API.
    

### שיטות עבודה מומלצות

1. **שימוש במשתני סביבה**: שמור נתונים רגישים כמו פרטי בסיס נתונים בקובץ `.env`.
    
2. **ארגון הקוד**: שמור מודלים, נתיבים ובקרים בתיקיות נפרדות לניהול קל יותר.
    
3. **שליטה בגרסאות**: השתמש ב-Git כדי לעקוב אחר שינויים בקוד.
    
4. **כתיבת הערות**: תעד את הקוד שלך להבנה טובה יותר.
    

זהו סיום מדריך ההקמה הבסיסי של הבקאנד. ניתן להרחיב את הבסיס הזה ולהוסיף תכונות מתקדמות כמו אימות משתמשים, ולידציה של נתונים ויכולות בזמן אמת באמצעות WebSockets.
